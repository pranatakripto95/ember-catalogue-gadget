**INFINICELL Self-Charging Power Bank — $79.00**

A catalogue photograph of an impossible gadget, drawn entirely in code
(`main.py`, Pillow, no external images). The INFINICELL power bank charges
itself: its own USB-C cable loops out of one port and straight back into
the other, its display holding at 100% forever. Its one accessory, a wall
charger, lies beside it — unused, and never needed.

Run it with:

```sh
python3 main.py   # writes /output/entry.png (1024x1024 PNG)
```
